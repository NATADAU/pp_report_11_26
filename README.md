# Аналитика первичных заявок · ЦЛП

Автономный дашборд в корпоративной палитре ЦЛП. Основной файл — `index.html`: HTML, стили, JavaScript и шрифт Montserrat находятся внутри него. Сборка и установка зависимостей не требуются.

## Возможности

- Обзор помесячной динамики за 2024–2026 годы.
- Общий возрастной профиль за 2019–2026 годы.
- Выбор одного или нескольких лет для сравнения возрастных групп: количество заявок или доли внутри года.
- Подробности по месяцам 2019 года открываются по запросу.
- Адаптация для мобильных экранов, крупный текст, встроенный шрифт с кириллицей.

## Открыть на компьютере

Скачайте `index.html` и откройте его в современном браузере. После скачивания интернет не требуется.

## Включить веб-ссылку через GitHub Pages

1. Откройте настройки Pages: https://github.com/NATADAU/pp_report_11_26/settings/pages
2. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
3. Выберите ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Дождитесь завершения публикации. GitHub покажет ссылку на сайт в настройках Pages.

Ожидаемый адрес после включения Pages: https://natadau.github.io/pp_report_11_26/

## Данные

Использованы только таблицы исходного HTML-отчёта; исходные значения сохранены. Единица учёта — заявка, а не уникальный человек или состоявшийся приём. Периоды имеют значение: в помесячном сравнении за 2026 год доступны январь–октябрь; возрастная таблица за 2026 год включает данные по 7 ноября. Неполный год помечен в интерфейсе.

Шрифт Montserrat встроен в HTML; сведения об авторских правах и лицензии сохранены в файле.
